# AI SaaS Platform

AI API SaaS Platform with Stripe billing. Built with Next.js 14.

## Pages

- `/` - Home
- `/features` - Features
- `/pricing` - Pricing
- `/about` - About
- `/contact` - Contact
- `/login` - Login
- `/dashboard` - Dashboard
- `/legal/terms` - Terms of Service
- `/legal/privacy` - Privacy Policy

## Setup

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import to Vercel
3. Add environment variables
4. Deploy
